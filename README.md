# Gestion des étudiants

Application de bureau pour gérer une liste d'étudiants : ajout, modification, suppression, recherche et statistiques. L'interface est réalisée avec CustomTkinter.

![Page d'accueil de l'application](images/accueil.png)

## Fonctionnalités

- Ajouter, modifier et supprimer des étudiants
- Notes décimales acceptées (par exemple 14,5)
- Recherche par nom
- Tri (A-Z ou meilleures notes) et filtres (admis, ajournés)
- Tableau de bord avec statistiques, graphiques et top 3
- Mode clair et mode sombre
- Sauvegarde automatique dans un fichier JSON

## Installation

1. Installer Python 3 sur votre ordinateur
2. Télécharger le projet :

```
git clone https://github.com/farajyaya8-rgb/gestion-etudiants-gui.git
cd gestion-etudiants-gui
```

3. Installer les bibliothèques nécessaires :

```
pip install -r requirements.txt
```

4. Lancer l'application :

```
python main.py
```
